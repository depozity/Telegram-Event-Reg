# Telegram-Event-Reg

Простой Telegram-бот для регистрации пользователей и отправки заявок админу.  
Первый бот, поэтому дрисня.

## 🚀 Функции
- Приветствие пользователя при старте
- Регистрация имени и фамилии
- Отправка данных админу (ID и username)
- Использование кнопок для удобного взаимодействия
